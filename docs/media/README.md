# ROUTE Media Resources

## Purpose

This folder gives reporters, editors, researchers, and public readers a reliable
starting point if they find ROUTE before a formal briefing.

These materials explain what ROUTE and Interstate 2.0 are, what can be safely
said, what remains evidence-gated, and which repo documents support the current
story.

This is not a press release, launch announcement, external rehearsal record, or
approval package. It does not create official-plan status, construction
readiness, guaranteed service, numeric ROI, funding eligibility, compliance,
agency endorsement, public-readiness, or external-readiness.

## Media-Safe Summary

ROUTE is a research and tooling project for Interstate 2.0: a proposal to think
about roads as a service network instead of one flat highway category.

The core idea is that different roads have different jobs: national freight
spine, regional connector, feeder/access layer, and terminal/local access.
ROUTE builds maps, ledgers, evidence labels, and review records that make those
roles inspectable.

The current materials are useful for explaining the concept and the evidence
discipline behind it. They are not proof that any named project should be built.

## Current Public Claim Boundary

| Safe To Say | Do Not Say |
|---|---|
| ROUTE frames Interstate 2.0 as a service-network vision. | Interstate 2.0 is an adopted official plan. |
| ROUTE can generate maps, ledgers, reviews, and evidence-bounded artifacts. | ROUTE proves which corridors must be built. |
| Service windows are planning targets used to reason about roles. | Service windows are guaranteed operating commitments. |
| Maps can make the service structure visible. | Maps prove SLA, upgrade, terminal, asset, or construction readiness. |
| ROI and cost work are treated as evidence contracts. | ROUTE has proven positive ROI for a corridor, hub, or standard. |
| Stakeholder requirements can refine the package through source custody and role review. | Stakeholders, agencies, or DOTs have endorsed the plan. |

## Recommended Attribution

Use language like:

> ROUTE is an evidence-bounded research and tooling project exploring an
> "Interstate 2.0" service hierarchy for roads.

Avoid language like:

> ROUTE is a federal plan, construction proposal, or adopted highway program.

## Contact And Corrections

No media contact is specified in this repository. If a story depends on a
current source, numeric claim, agency position, or public-readiness status,
verify it outside this repo before publication.

If a claim in these materials appears to conflict with the evidence posture,
use `docs/reports/route-evidence-posture.md` as the controlling boundary.
