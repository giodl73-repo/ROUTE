# Blueprint Phase Sequence

This sequence keeps Milepost 6 from reading like a shopping list. Packages move only when their evidence and cost gates allow them to move.

## Phase 0: Measure Before Building

1. `B6-P0-REST-WIM-BRIDGE` comes first because planned standards need asset and source foundations before they can support design scope.
2. `B6-P0-RELAY-OPS` follows as a low-footprint operations candidate. It can enter Blueprint sequencing with a heuristic label, but SLA/PTI claims remain held until direct evidence exists.

## Phase 1: Proof Targets And Companions

3. `B6-P1-DIAMOND-RECOVERY` is a proof target, not a benefit claim. It waits on top-site geometry, failure-rate, and restoration validation.
4. `B6-P1-DONNER-CALIBRATION` upgrades the mountain-pass fixture into a loaded stressor before any resilience claim is allowed.
5. `B6-P1-EV-REST-MITIGATION` prepares the mitigation package that expansion pilots need around rest, charging, truck parking, and utility capacity.
6. `B6-P1-MANAGED-LANE-PILOT` can only move after corridor PTI baselines and mitigation companions exist.

## Phase 2: Conditional System Relief

7. `B6-P2-INTERMODAL-DIVERSION` stays held until terminal, rail, and drayage capacity evidence exists.
8. `B6-P2-RURAL-SPURS` must pass a rural-access exception docket so true gaps are not confused with centroid artifacts.
9. `B6-P2-T2-RELIEF` is last because relief corridors require loaded-stressor and per-dollar intervention sensitivity before scope selection.

## Promotion Rule

The package order is not a construction order. It is an evidence order. A later package may be researched early, but it cannot be promoted in the design spec until its row in `data/blueprint-phase-sequence.csv` names a satisfied gate and the package remains consistent with `data/blueprint-evidence-map.csv` and `data/blueprint-cost-ranges.csv`.
