# ROUTE — planner / researcher brief

**Time:** 15–25 minutes. **Goal:** understand Interstate 2.0 as service promises
with held claims, not as a build list.

## Core idea

| Tier | Promise posture | Job |
|---|---|---|
| T1 | National timed-freight spine | Coast-to-coast / half-continent |
| T2 | Regional connector / relief | Mega-region links feeding T1 |
| T3 | Feeder / access mesh | Production, ports, smaller metros, rural |
| T4 | Terminal access | Port, yard, warehouse, border, last mile |

ROUTE scores what exists, classifies service, maps gaps, and accepts a rigorous
null when intervention is not supported.

## 15-minute proof

```powershell
npm run proof:public
```

Details: [`../how-to/public-proof.md`](../how-to/public-proof.md).

Pass means the I-80 flagship review packet still builds, no-credential sources
are honest, and posture remains **hold and narrow**.

## Safe language

- “Research and tooling lab for Interstate 2.0 service promises.”
- “Hold-and-narrow I-80 review packet.”
- “Evidence-gated gaps; null results allowed.”

## Unsafe language

- “Approved national plan.”
- “Ready to build / fund / procure.”
- “Guaranteed 48h freight SLA.”
