# Full State System Tierization Slate 010

## Scope

This slate reworks Kansas, Nebraska, North Dakota, and Montana into full-state
tierization samples.

## State Pressure Tests

| State | Full-system question |
|---|---|
| Kansas | Which plains, agriculture, energy, Wichita/Kansas City, and western rural roles keep the state system from collapsing into I-70/I-35 only? |
| Nebraska | Which Platte corridor, north-south agriculture, Sandhills, airport, and river-terminal roles need explicit service treatment? |
| North Dakota | Which northern tier, Canadian gateway, energy-region, agriculture-terminal, and winter recovery roles make the sparse network testable? |
| Montana | Which mountain pass, Canadian gateway, northern tier, rail/agriculture, and recreation access roles should be tiered before any promise is sold? |

## Evidence Boundary

These are tierization samples, not full source-backed state inventories. They do
not claim official state designation, legal SLA, construction readiness, cost,
numeric ROI, funding eligibility, compliance, endorsement, external validation,
public readiness, or state approval.
