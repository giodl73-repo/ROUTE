# Full State System Tierization Slate 002

## Scope

This slate reworks New York, Illinois, Georgia, and Pennsylvania into
full-state tierization samples.

## State Pressure Tests

| State | Full-system question |
|---|---|
| New York | Which non-Thruway and North Country roles reduce downstate/upstate overconcentration and cross-Hudson terminal friction? |
| Illinois | Which central, western, southern, river, and terminal roles make the system more than Chicago-statewide interstate spines? |
| Georgia | Which South Georgia, port, rural, and east-west roles should be formalized beyond Atlanta-centered trunks? |
| Pennsylvania | Which US/state routes provide real redundancy for Turnpike/I-81 dependence across mountains, Northeast PA, Lake Erie, and Philadelphia port access? |

## Evidence Boundary

These are tierization samples, not full source-backed state inventories. They do
not claim official state designation, legal SLA, construction readiness, cost,
numeric ROI, funding eligibility, compliance, endorsement, external validation,
public readiness, or state approval.
