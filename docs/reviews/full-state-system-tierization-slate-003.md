# Full State System Tierization Slate 003

## Scope

This slate reworks Ohio, North Carolina, Michigan, and Washington into
full-state tierization samples.

## State Pressure Tests

| State | Full-system question |
|---|---|
| Ohio | Which Appalachian, Ohio River, manufacturing, and terminal roles make the system more than the 3C/interstate mesh? |
| North Carolina | Which mountain, coastal, eastern, port, and barrier-island roles need formal service treatment beyond the Piedmont trunks? |
| Michigan | Which northern, Upper Peninsula, bridge, port, and west-Michigan roles complete the peninsula system beyond Detroit-centered trunks? |
| Washington | Which pass, port, rural/agricultural, border, and eastern roles make the state resilient beyond I-5 and I-90? |

## Evidence Boundary

These are tierization samples, not full source-backed state inventories. They do
not claim official state designation, legal SLA, construction readiness, cost,
numeric ROI, funding eligibility, compliance, endorsement, external validation,
public readiness, or state approval.
