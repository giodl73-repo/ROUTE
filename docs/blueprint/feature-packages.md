# Blueprint Feature Packages

This file is the human-readable companion to `data/blueprint-feature-packages.csv`. The CSV is the gateable source of truth; this document explains how the packages should be used in Milepost 6.

## Package Classes

`operational_must_have` packages are allowed into early Blueprint work when they improve reliability measurement or operations without requiring a new expansion benefit claim. They still keep their evidence label.

`source_gated_must_have` packages are necessary to make the design measurable, but they cannot become design claims until the named source gap is closed.

`conditional_expansion` packages are high-blast-radius investments. They require mitigation, ROW complexity, lifecycle maintenance, community exposure, and a held/heuristic evidence label until direct source evidence exists.

`mitigation_companion` packages are not optional decoration. They are the companion investments needed before expansion packages can be framed as responsible design proposals.

## Phase 0 Measurement And Operations

`B6-P0-RELAY-OPS` is the first operational candidate. It packages relay and intelligent-routing operations as a low-footprint reliability seed, but it does not claim SLA/PTI proof. The blocker is still operator rosters plus NPMRDS/FPM validation.

`B6-P0-REST-WIM-BRIDGE` is a source-foundation package. Rest areas, WIM, bridge condition, clearance, and maintenance rows must become measurable before planned standards can be promoted into design scope.

## Phase 1 Proof Targets

`B6-P1-DIAMOND-RECOVERY` keeps T1/T1 diamond recovery zones as a proof target. It can organize geometry, failure, and reroute evidence, but benefit claims remain held until k-connectivity and throughput restoration are validated.

`B6-P1-DONNER-CALIBRATION` keeps the Donner mountain-pass scenario in calibration mode. The current no-delta fixture is useful for readiness, not for benefit claims.

`B6-P1-MANAGED-LANE-PILOT` is conditional expansion only. It needs corridor PTI baselines, community exposure review, enforcement/operations lifecycle costs, and companion mitigation before it can move beyond a held pilot.

`B6-P1-EV-REST-MITIGATION` is the companion package for rest reliability, charging, and truck parking around operations and expansion packages. It needs utilization, uptime, and utility-capacity sources.

## Phase 2 Conditional System Relief

`B6-P2-INTERMODAL-DIVERSION` is a held mitigation package for port surge and diversion capacity. It needs terminal throughput, rail capacity, drayage reliability, and neighborhood exposure evidence.

`B6-P2-RURAL-SPURS` is a source-gated rural access package. It must distinguish true rural access gaps from centroid or source artifacts before scope promotion.

`B6-P2-T2-RELIEF` is conditional expansion for relief and resilience corridors. No-delta pressure scenarios can keep it in the docket, but promotion requires loaded-stressor intervention sensitivity.

## Promotion Rule

A package can move from held/backlog to `blueprint_candidate` only when the next evidence step is satisfied or the claim is explicitly downgraded. `blueprint_candidate` never means proven; it means the package is allowed into Blueprint sequencing with its current evidence label visible.
