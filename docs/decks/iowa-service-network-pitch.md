# Iowa Service Network Pitch

## Slide 1 - The Question

Iowa already has roads.

The question is what service the state highway system should promise.

Speaker note:
ROUTE starts with the client's priorities, not a finished map. The first
conversation is about the places, movements, and failures that matter most.

## Slide 2 - The Offer

Give ROUTE the places Iowa must connect:

- top cities and regional centers,
- freight nodes and production regions,
- hospitals, campuses, airports, river terminals, rail yards, and industrial
  parks,
- rural access needs,
- known closure, snow, flood, bridge, work-zone, and incident risks.

ROUTE turns those priorities into a service network: tiers, planning promises,
resilience standards, investment packages, and a dashboard.

## Slide 3 - What Changes

Traditional question:

> Which roads are on the map?

ROUTE question:

> What must the system deliver, and where would failure be unacceptable?

Speaker note:
The product is not a source audit and not a static map. The product is a way
to make state priorities operational: which places get the strongest promise,
which access needs should not be erased, which failures need alternates, and
which investments should move first.

## Slide 4 - Service Roles

| Role | Iowa Question |
|---|---|
| T1 state spine | Which top city pairs and national gateways need the strongest reliability target? |
| T2 regional connectors | Which secondary cities, campuses, hospitals, and job centers need predictable access to the spine? |
| T3 rural and production access | Which agricultural, manufacturing, energy, and rural-service areas must stay visible? |
| T4 terminal and local access | Which airports, river terminals, rail yards, hospitals, campuses, downtowns, and industrial parks create last-mile service needs? |
| R resilience overlay | Which failures would break Iowa's service promise? |

## Slide 5 - Candidate Promise Menu

ROUTE helps Iowa design planning targets for:

- reliable movement among top cities and gateways,
- regional access to jobs, hospitals, campuses, and freight districts,
- rural production visibility,
- first/last-mile terminal access,
- flood, snow, bridge, work-zone, incident, and detour resilience,
- staged investment packages,
- executive dashboard reporting.

Speaker note:
These are design promises to refine. They are not legal guarantees unless the
client later adopts targets, ownership, funding, operating rules, and review
process.

## Slide 6 - The 90-Day Package

| Phase | ROUTE Output |
|---|---|
| Priority intake | Intake map and promise backlog |
| Tier design | Draft service hierarchy and tier promise table |
| Promise design | Candidate service targets by tier and failure mode |
| Resilience blueprint | Critical failure map, alternate-route standards, and recovery target menu |
| Investment packaging | Quick wins, operating fixes, asset fixes, terminal access, rural access, and capital sequence |
| Dashboard design | Executive dashboard spec for reliability, access, recovery, asset condition, bottlenecks, and package progress |

## Slide 7 - What Leaders Get

| Leader Need | ROUTE Output |
|---|---|
| Clear story | A service promise for Iowa's people, economy, and regions |
| Practical sequencing | Operational fixes, asset fixes, access packages, resilience hardening, and larger capital options separated |
| Better tradeoffs | Tiers and promise labels show what gets priority and why |
| Resilience posture | Unacceptable failures and backup expectations are named before crisis |
| Management view | Dashboard questions are designed before adoption |

## Slide 8 - What This Is Not

ROUTE is not asking Iowa to approve:

- an official state DOT plan,
- a route designation,
- a legal SLA,
- a construction program,
- a funding commitment,
- environmental or right-of-way clearance,
- ROI proof,
- public-ready validation.

ROUTE is asking Iowa to define the service network it wants to evaluate.

## Slide 9 - The First Meeting

The first meeting is a 90-minute discovery workshop.

The client answers:

- Which places must stay connected?
- Which movements deserve the strongest promise?
- Which failures would be unacceptable?
- Which bottlenecks limit the promise?
- Which package should move first?

ROUTE returns the first service hierarchy, promise backlog, resilience agenda,
investment sequence, and dashboard questions.

## Slide 10 - Close

Start with one decision:

> What places in Iowa must stay connected, and what failure would be
> unacceptable?

ROUTE turns that answer into a state service-network package.
