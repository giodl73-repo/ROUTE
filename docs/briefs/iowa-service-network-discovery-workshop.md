# Iowa Service Network Discovery Workshop

## Purpose

This is the first working session for a state client that wants ROUTE as a
service-network design product.

The meeting does not ask the client to approve a map. It asks the client to
name the places, failures, economic movements, and public-service obligations
that the highway system must serve. ROUTE converts those choices into a draft
service hierarchy, promise backlog, resilience agenda, investment package
sequence, and dashboard specification.

## Workshop Outcome

By the end of the session, the client should have a working answer to five
questions:

| Question | ROUTE Output |
|---|---|
| Which places must stay connected? | Priority place list and first-pass service hierarchy |
| Which movements deserve the strongest promise? | Candidate T1/T2/T3/T4 roles and promise backlog |
| Which failures would be unacceptable? | Resilience stressor list and recovery-target menu |
| Which bottlenecks limit the promise? | Access, terminal, interchange, bridge, incident, and local-constraint backlog |
| Which package should move first? | 30/60/90-day action list and candidate investment sequence |

## Attendees

Use the smallest group that can make priority tradeoffs.

| Role | What They Bring |
|---|---|
| Executive sponsor | The service promise the state wants leaders to be able to say out loud |
| State DOT planner | Network roles, planned projects, constraints, and practical sequencing |
| Operations lead | Closures, incidents, winter operations, detours, and recovery reality |
| Freight/economic development lead | Industrial parks, terminals, production regions, major employers, and bottlenecks |
| Rural/access representative | County-seat, hospital, agricultural, and low-density access priorities |
| MPO/local representative | Metro connectors, last-mile friction, downtown access, and local delivery constraints |
| Finance/program lead | Budget posture, grant windows, match exposure, and delivery capacity |

## Intake Board

The client fills this board before or during the session.

| Prompt | Client Answer |
|---|---|
| Top cities and regional centers that must stay connected | |

## Service Tier Sorting

Sort each priority into the role it needs to play. A place or corridor can
belong to more than one role when it has both movement and resilience value.

| Tier | Client Decision | ROUTE Draft Output |
|---|---|---|
| T1 state spine | Which city pairs and national gateways need the highest reliability target? | Candidate top-tier service network |
| T2 regional connectors | Which regions, campuses, hospitals, and job centers need reliable access to the spine? | Regional connector map and promise table |
| T3 rural and production access | Which agricultural, energy, manufacturing, and rural-service areas must stay visible? | Rural/production access layer |
| T4 terminal and local access | Which airports, river terminals, rail yards, hospitals, universities, downtowns, and industrial parks are service-critical? | Last-mile service backlog |
| R resilience overlay | Which closures or failures would break the state service promise? | Alternate-route and recovery target menu |

## Promise Design Menu

These are planning promises to select and refine. They are not legal service
guarantees unless the client later adopts targets, operating rules, ownership,
funding, and review process.

| Promise Type | Workshop Choice |
|---|---|
| Reliability | Which movements should be protected from chronic delay, recurring closure, or unmanaged detour risk? |
| Access | Which places should be treated as service-critical even when traffic volumes are modest? |
| Recovery | Which failures need a named recovery expectation by tier? |
| Redundancy | Which links need practical alternates before the next flood, snow event, bridge restriction, crash, or work zone? |
| Last mile | Which terminal, airport, hospital, campus, downtown, or industrial park gaps create service failure? |
| Investment | Which fixes are operational, which are asset-focused, and which are capital packages? |
| Dashboard | Which indicators should executives see every month? |

## 90-Minute Agenda

| Time | Work |
|---|---|
| 0-10 minutes | Confirm the client promise: what Iowa should be able to say the network delivers |
| 10-25 minutes | Name priority places, gateways, production regions, terminals, hospitals, campuses, and political gaps |
| 25-45 minutes | Sort priorities into T1, T2, T3, T4, and resilience roles |
| 45-60 minutes | Name unacceptable failures and weak alternates |
| 60-75 minutes | Group fixes into operations, asset, terminal, rural access, resilience, and capital packages |
| 75-90 minutes | Choose the first 30/60/90-day package and dashboard questions |

## Immediate ROUTE Deliverables

After the workshop, ROUTE should be able to produce:

| Timing | Deliverable |
|---|---|
| 48 hours | Workshop readout: priorities, unresolved tradeoffs, claim holds, and next-source needs |
| 1 week | Draft Iowa service hierarchy and promise backlog |
| 2 weeks | Resilience stressor map and alternate-route target menu |
| 30 days | First investment package sequence and dashboard specification |
| 90 days | Client-ready service-network package with review notes, evidence gaps, and adoption options |

## Boundaries

Do not present workshop outputs as an official Iowa DOT plan, route
designation, legal SLA, construction program, funding commitment,
environmental clearance, right-of-way clearance, ROI proof, external
validation, or public-ready map.

The workshop produces client requirements and planning targets. Adoption,
engineering, funding, source validation, public process, and operating
commitments remain later gates.
