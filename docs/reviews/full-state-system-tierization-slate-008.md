# Full State System Tierization Slate 008

## Scope

This slate reworks Oklahoma, Arkansas, Mississippi, and New Jersey into
full-state tierization samples.

## State Pressure Tests

| State | Full-system question |
|---|---|
| Oklahoma | Which plains, Panhandle, inland port, and eastern freight roles backstop the I-35/I-40 crossroads? |
| Arkansas | Which Delta, Ozark, river terminal, northeast, and flood-resilience roles make the system more than I-40/I-49? |
| Mississippi | Which Gulf, Delta, river, evacuation, and rural roles backstop I-55/I-20? |
| New Jersey | Which turnpike, parkway, port, shore, dense urban, and restricted-route roles need explicit service treatment? |

## Evidence Boundary

These are tierization samples, not full source-backed state inventories. They do
not claim official state designation, legal SLA, construction readiness, cost,
numeric ROI, funding eligibility, compliance, endorsement, external validation,
public readiness, or state approval.
