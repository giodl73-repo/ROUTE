# ROUTE DCR Renewal Gate 001

## Purpose

The DCR renewal gate explains why a buyer pays after the proposal and after the
30-90 day pilot.

The answer is not that ROUTE produced a prettier report. The buyer pays because
the DCR maintains operating memory: what changed, which service promises are at
risk, which switch options have been rehearsed, which signage/routing or EV
support postures need review, and which claims remain unsafe.

## Enduring Value

The enduring value is the maintained state of the system.

| Maintained Asset | Renewal Value |
|---|---|
| Service hierarchy | The buyer does not restart from a stale map when priorities change. |
| Promise ledger | Leadership language stays tied to current evidence and legal-SLA holds. |
| Failure-mode ledger | Recurring problems become visible before a crisis makes them political. |
| Monitoring history | Exceptions, source status, and unresolved holds accumulate into operating memory. |
| Simulation library | Closure, EV, signage, terminal, weather, and package scenarios get faster to rerun. |
| Switch playbooks | Repeated decisions become governed options instead of improvised reactions. |
| Evidence boundary | Claims are held, refreshed, or downgraded before they leak into public language. |
| Executive cadence | Sponsors get a repeatable board-safe update instead of a one-off deck. |
| Source custody | Source owners, permissions, refresh windows, and use limits reduce restart cost. |
| Renewal backlog | The next product is tied to observed demand, not a vague platform pitch. |

## Renewal Paths

| Path | Use When | Buyer Value |
|---|---|---|
| DCR quarterly review | The buyer has recurring exceptions, held claims, or executive reporting needs. | Keeps monitoring, simulation, evidence, and switch playbooks current. |
| DCR event review | A closure, incident, charger outage, terminal failure, weather event, or near miss creates a decision question. | Replays what happened and updates operating posture. |
| DCR workbench | Repeat users need scenarios, exports, and evidence ledgers without manual deck work. | Converts retained DCR work into a usable decision surface. |
| DCR source integration | Approved advisory feeds can reduce manual loading. | Lowers restart cost while preserving advisory boundaries. |
| Signage/routing advisory package | Route choice, message-board, truck, local access, or traveler information posture keeps recurring. | Creates an operator-reviewed advisory queue. |
| EV support advisory package | EV range, charging, staging, queue, weather, or fleet resilience risk keeps recurring. | Maintains EV-sensitive route and support posture. |
| Stop or hold | No recurring question, sponsor, source path, or authority path exists. | Avoids over-selling and preserves credibility. |

## Renewal Gate

Renew only when at least one of these is true:

- a maintained asset changed during the pilot;
- the buyer reviewed the same decision class more than once;
- a disruption, near miss, or leadership event created a bounded event-review
  trigger;
- a source owner, permission, refresh window, or manual fixture moved from held
  to usable;
- a claim boundary mattered because language was held, downgraded, expired, or
  made safer;
- an authorized operator, owner, or sponsor reviewed a switch option.

Stop or hold when no maintained asset changed, no event occurred, no repeated
decision appeared, and no sponsor wants a cadence.

## Commercial Close

The close should be:

> The pilot created an operating record. We can keep that record current,
> rerun the decisions that matter, and preserve the claim boundaries that keep
> leadership safe.

Do not close on ROI proof, procurement readiness, state endorsement, live
integration, automated control, legal detours, traffic control, guaranteed SLA,
EV availability, public readiness, or construction proof.

## Boundary

The renewal gate is a continuation decision aid. It does not prove ROI,
procurement readiness, agency endorsement, public readiness, construction
readiness, legal detour authority, traffic-control authority, live integration,
automated control, incident command, guaranteed SLA, or EV availability.

Every renewal path must preserve the distinction between advisory simulation,
operator-approved action, and evidence-backed claim.
