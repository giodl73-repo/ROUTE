# Source-Backed Stakeholder Fixture 006

## Purpose

This fixture closes one bounded transit-dependent, intercity traveler, and
non-driving access source-backed example for the industry/stakeholder fixture
campaign.

It uses FTA rural transit material and the FTA Rural Areas Formula Program
circular to show that rural public transportation, intercity bus connections,
planning, marketing, facilities, and connections between rural areas and larger
regional or national intercity bus systems are real review lanes for ROUTE.

This fixture does not create FTA, state DOT, transit agency, carrier,
passenger, rural community, or accessibility advocate endorsement. It does not
prove transit service, intercity bus service, stop location, facility quality,
first/last-mile connection, ridership, accessibility compliance, funding
eligibility, construction readiness, guaranteed service, numeric ROI, approval,
public readiness, or external readiness.

## Evidence Boundary

| Safe Finding | Held Finding |
|---|---|
| FTA rural transit material supports treating rural public transportation as a real planning and operating-assistance domain. | ROUTE has identified, funded, or improved a rural transit service. |
| FTA rural program guidance supports treating intercity bus connections between rural areas and larger regional or national systems as a review lane. | ROUTE proves an intercity bus route, stop, shelter, joint-use facility, or first/last-mile connection exists or is adequate. |
| ROUTE can use these sources to justify keeping non-driving access visible in T3/T4 intake, state packets, and evidence ledgers. | Any transit agency, carrier, state DOT, FTA, passenger group, rural community, or accessibility advocate endorses Interstate 2.0 or ROUTE. |
| A non-driving access fixture can close as a hold or exclusion row when service/facility evidence is missing. | ROUTE has demonstrated accessibility compliance, rider benefit, ridership, safety, service frequency, or public-readiness. |

## Gate

Rationale: This fixture provides a bounded source-backed non-driving access
example. ROUTE can cite rural transit, intercity bus connection, facility,
planning, and first/last-mile questions as real review controls. It does not
authorize named service, stop, facility, accessibility compliance, ridership,
funding, eligibility, endorsement, approval, public-readiness,
