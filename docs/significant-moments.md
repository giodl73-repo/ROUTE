# Significant Moments

This ledger tracks conceptual breakthroughs that change how the system thinks.
It is not a changelog. A moment belongs here when it changes selection doctrine,
map grammar, evidence policy, gameplay language, or the way future milestones
should be judged.

Canonical rows live in `data/significant-moments.csv`.

## Flair Rules

- A flair should be short enough to remember.
- A moment should name the idea, not just the file change.
- The `why_it_mattered` field should explain what future work now does
  differently.
- The `primary_artifacts` field should point to the files that preserve the
  breakthrough.
- The `next_thread` field should say what work naturally follows.
