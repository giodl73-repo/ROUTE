# Full State System Tierization Slate 007

## Scope

This slate reworks Indiana, South Carolina, Maryland, and Nevada into
full-state tierization samples.

## State Pressure Tests

| State | Full-system question |
|---|---|
| Indiana | Which US-route, port, river, and southern-rural roles make the crossroads system more than I-65/I-70? |
| South Carolina | Which coastal, port, Lowcountry, evacuation, and rural roles backstop I-26/I-95? |
| Maryland | Which Chesapeake, port/tunnel, Eastern Shore, southern Maryland, and restricted-route roles need explicit treatment? |
| Nevada | Which US 95/US 50, desert, airport, sparse-service, and winter/heat roles reduce dependence on I-15/I-80? |

## Evidence Boundary

These are tierization samples, not full source-backed state inventories. They do
not claim official state designation, legal SLA, construction readiness, cost,
numeric ROI, funding eligibility, compliance, endorsement, external validation,
public readiness, or state approval.
