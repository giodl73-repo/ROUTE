# Interstate 2.0 State Value Brief

## The State Pitch

Interstate 2.0 should not be sold as Washington handing states a finished map.
It should be sold as a national service framework that lets states show why
their corridors, hubs, access needs, resilience gaps, and freight priorities
matter to the country.

The state value proposition:

```text
state priority -> national service role -> staged package -> evidence need -> fundable ask
```

## What States Get

| State Need | Interstate 2.0 Answer |
|---|---|
| A stronger national case | State priorities can be framed as freight reliability, rural access, resilience, port/border performance, or relay-hub value. |
| A way to shape the plan | State requirements become inputs that can change corridors, hubs, stops, staging, evidence status, or claim labels. |
| A staged funding path | Large visions can be split into planning, evidence, hub, charging, safety, interchange, access, and corridor packages. |
| More honest risk handling | Delivery, right-of-way, source, environmental, maintenance, and community blockers stay visible instead of being hidden. |
| A coalition story | Governors and legislators can talk about jobs, access, reliability, competitiveness, and resilience without pretending every project is ready. |

## Governor-Safe Boundary

Safe line:

> This state is exploring how its transportation priorities could be mapped to a
> national service framework. The work is at the intake and evidence stage. It
> does not endorse a map, authorize construction, guarantee service windows,
> prove ROI, or replace state, MPO, FHWA, environmental, safety, civil-rights, or
> public-involvement processes.

## State-Specific Questions To Ask

| Question | Why It Matters |
|---|---|
| Which state priorities have national freight, access, or resilience value? | Turns local asks into national relevance. |
| Which corridors or hubs could support a T1, T2, T3, or T4 service promise? | Connects projects to a service role instead of a road label. |
| Where does the state need redundancy before the next closure or disaster? | Makes resilience concrete and fundable. |
| Which rural, agricultural, port, border, or production-zone access needs are invisible in volume-only planning? | Keeps lower-density but high-value access from being erased. |
| What delivery constraints should hold or reshape the plan? | Preserves state DOT authority and practical feasibility. |
| Which community concerns need to enter early? | Prevents the plan from becoming politically brittle. |

## State Delivery Checklist

No state-facing option should be treated as fundable until these delivery
questions are explicit.

| Delivery Area | What To Capture |
|---|---|
| Match funding | Likely federal program fit, state match exposure, local contribution, and grant timing. |
| Maintenance burden | Added lane-mile, bridge, hub, charging, inspection, snow/ice, and operations obligations. |
| Right-of-way | Existing alignment, greenfield exposure, utility conflicts, rail/utility easement possibilities, and acquisition risk. |
| Environmental review | NEPA path, sensitive areas, community-health issues, habitat, water, runoff, noise, and mitigation needs. |
| Lifecycle cost | Capital vs. operations vs. maintenance vs. replacement costs over the selected horizon. |
| Phasing | What can be studied, piloted, built, or deferred in each funding window. |
| Agency authority | Which claims require state DOT, MPO, FHWA, port, toll, transit, or local-government action. |

## Staged Ask Menu

States do not need to start with a mega-project. A fundable Interstate 2.0
package can begin with smaller pieces:

| Package | What It Buys |
|---|---|
| State service view | A state-specific T1/T2/T3/T4 story and map explanation. |
| Requirement intake | A structured way for state DOT, freight, rural, community, and industry requirements to refine the plan. |
| Evidence campaign | Source acquisition and scenario work for the state's most important claims. |
| Relay-hub pilot | A hub, charging, staging, workforce, or handoff concept suitable for review. |
| Resilience pilot | Closure, interchange, flood, mountain-pass, port, or evacuation stress testing. |
| Access package | Rural, agricultural, production-zone, port, border, warehouse, or terminal access review. |
| Decision package | A funder-facing option set with benefits, costs, evidence labels, blockers, and next steps. |

## State-To-AASHTO Regional Packet

Before a state carries this package into a regional association setting, prepare
`docs/briefs/state-to-aashto-regional-packet.md`.

| Packet Field | Why It Matters |
|---|---|
| Shared corridors / service questions | Keeps the discussion regional instead of one-state advocacy. |
| Cross-border OD lanes | Gives freight and passenger service claims a sourceable question. |
| Terminal, port, border, and rural access | Keeps local access from being erased by the national map. |
| Reliability / PTI evidence needs | Blocks guaranteed-SLA language. |
| Resilience stressors | Turns closure, weather, port, and evacuation concerns into evidence rows. |
| Delivery constraints | Preserves match, maintenance, ROW, environmental review, lifecycle, and phasing. |
| Holds and dissent | Shows what must stay blocked or challenged. |
| Non-claims | Repeats no official plan, construction readiness, guaranteed service, numeric ROI, eligibility, or endorsement. |

## What To Say

| Message | Safe Wording |
|---|---|
| National relevance | "This helps show where a state priority serves the national network." |
| State agency role | "This is a planning and evidence tool, not a replacement for state DOT engineering or delivery authority." |
| Funding | "This can turn a big vision into staged packages that match funding windows." |
| Evidence | "The framework shows what is ready, what is heuristic, and what needs more proof." |
| Communities | "Concerns can enter before the map hardens." |
| Service promises | "T1/T2/T3/T4 promises are planning targets until reliability and delivery evidence close." |

## What Not To Say Yet

- This proves any state project should be built.
- This is an official federal or state plan.
- This resolves right-of-way, environmental, maintenance, or delivery risk.
- This proves positive ROI for any corridor, hub, or standard.
- This proves SLA readiness for any map surface.

## Role Review Notes

| Role Lens | Finding | Disposition |
|---|---|---|
| Scope Keeper | Brief frames state value and staged planning; it does not prescribe construction or claim agency readiness. | pass |
| State DOT Planner | State authority, delivery constraints, and funding windows remain explicit. | pass |
| Citation Auditor | No external numbers or unsupported source claims are introduced. | pass |
| Numeracy Checker | No cost, ROI, volume, or benefit totals are introduced. | pass |
| Stakeholder Review | Rural, community, environmental, non-driving access, freight, and industry concerns are treated as plan inputs. | pass_with_risk |

## Gate

Decision: pass_with_risk

Rationale: This brief is suitable for state-facing positioning and intake
planning. It remains blocked from corridor-specific, ROI, construction,
official-plan, or SLA-readiness claims until source evidence and role review
close for a concrete state package.
