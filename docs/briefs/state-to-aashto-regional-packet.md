# State-To-AASHTO Regional Packet

## Purpose

Use this packet to carry a state conversation into a multi-state AASHTO regional
association rehearsal.

This packet is not a request for regional endorsement, route selection,
construction authorization, cross-border commitment, eligibility finding,
guaranteed service level, or numeric ROI claim.

## Regional Opening

Safe opening line:

> This is shared service evidence, not a state win map. The goal is to expose
> which regional claims need sources, sensitivity, dissent, and owner review
> before any option is promoted.

## What Changes The Answer?

Regional reviewers should ask which assumptions would change a candidate,
evidence label, or hold.

| Assumption | Could Change | Evidence Needed |
|---|---|---|
| OD demand or commodity flow | Freight priority, relay pilot, ROI source-pack scope. | OD source, commodity source, industry data owner. |
| Reliability / PTI evidence | T1/T2 service claim or managed-lane candidate. | Observed reliability source or bounded model. |
| Contact / terminal proof | T3/T4 access posture. | Route-to-terminal or route-to-contact source. |
| Bridge / weight / clearance constraint | Freight operating claim or route hold. | Bridge, permit, clearance, or owner source. |
| Hazard / closure assumption | Resilience pilot or hardening evidence ask. | Hazard source, closure source, recovery assumption. |
| Delivery constraint | Funding, phasing, or hold status. | State delivery review and owner. |
| Source quality | Promotion, hold, or downgrade. | Source title, date, access note, reviewer. |

Outputs remain limited to changed candidates, held claims, evidence asks, source
packs, or bounded pilots. They are not construction recommendations.

## Governance Non-Claim

ROUTE does not create authority, governance, eligibility, funding entitlement,
cross-border commitments, or official regional designations. It structures
evidence for existing state, regional, FHWA/USDOT, legislative, and public review
processes.
