# Full State System Tierization Slate 009

## Scope

This slate reworks Utah, New Mexico, Idaho, and Maine into full-state
tierization samples.

## State Pressure Tests

| State | Full-system question |
|---|---|
| Utah | Which intermountain trunk, winter pass, airport, eastern rural, and state-route redundancy roles make the system more than I-15? |
| New Mexico | Which border, desert, Four Corners, plains, and Rio Grande roles backstop I-25/I-40 service promises? |
| Idaho | Which north-south, panhandle, mountain, agricultural terminal, and sparse-service roles make the state network coherent? |
| Maine | Which Canadian gateway, coastal, northern rural, forest/agricultural, port, and winter access roles need explicit service treatment? |

## Evidence Boundary

These are tierization samples, not full source-backed state inventories. They do
not claim official state designation, legal SLA, construction readiness, cost,
numeric ROI, funding eligibility, compliance, endorsement, external validation,
public readiness, or state approval.
