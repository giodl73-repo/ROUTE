# Round 2 State Intake Payload

## Purpose

Use this payload to prepare a state DOT / governor-sponsor review and to create
the state-to-regional handoff.

This is not an endorsement form. It does not approve a map, authorize
construction, guarantee service levels, prove ROI, or replace state, MPO, FHWA,
environmental, safety, civil-rights, or public-involvement processes.
