# Local / Regional Interstate 2.0 Intake Template

## Purpose

Use this template after an intra-state regional planning meeting, MPO/RPO
meeting, freight advisory meeting, or state district meeting.

This template turns concerns into evidence rows. It does not select projects,
approve routes, prove maps, guarantee service windows, estimate ROI, or imply
state, local, federal, or stakeholder endorsement.
